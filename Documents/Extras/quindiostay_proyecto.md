# Proyecto final: QuindíoStay

Una plataforma de **turismo y hotelería** para alojamientos del Quindío —fincas, glampings y hoteles boutique— que necesita gestionar propiedades, habitaciones, tarifas por temporada, huéspedes, reservas, servicios adicionales, pagos y calificaciones.

El mismo caso te acompaña los cuatro núcleos: primero lo analizas, luego lo modelas y normalizas, después lo implementas en Oracle y finalmente lo consultas y reporteas.

## Requisitos del producto

| Requisito | Especificación |
| :--- | :--- |
| **Equipos** | Máximo 3 estudiantes |
| **Modelo de datos** | Mínimo **10 entidades fuertes**, correctamente normalizado |
| **Funcionalidad** | **CRUD** completo sobre las entidades principales |
| **Reportes** | **10 reportes exportables a PDF**: 3 simples, 4 intermedios y 3 avanzados |
| **Sustentación** | Defensa oral con **factor multiplicador 1** sobre la nota del producto |
